خدمة الأمير – النسخة التأسيسية الأولى
=====================================

مهم جدًا
--------
هذه نسخة تأسيسية قابلة للربط بقاعدة بيانات سحابية، وليست APK نهائيًا بعد.
لا تدخل بيانات أطفال حقيقية قبل أن تُكمل الكنيسة إعداد الحسابات والصلاحيات،
وتراجع سياسة الخصوصية وموافقة أولياء الأمور. لا ترسل كلمات مرورك أو مفاتيح
الخدمة السرية لأي شخص.

ما الذي يعمل في هذه النسخة؟
---------------------------
- واجهة عربية RTL قابلة للعرض على الموبايل.
- تسجيل دخول وطلب حساب جديد.
- الحساب الجديد يظل معلقًا حتى اعتماده.
- قراءة قائمة الأطفال حسب صلاحية المجموعة.
- إضافة طفل لأمين المجموعة/الإدارة.
- تسجيل حضور/غياب.
- سجل تعديلات أساسي للإدارة وأمين المجموعة.
- قاعدة بيانات مشتركة عند ربط Supabase.

ما الذي لم يكتمل بعد؟
---------------------
- لا يوجد ملف APK جاهز في هذه الحزمة.
- لا توجد إشعارات Push حقيقية بعد.
- لا توجد تقارير متقدمة أو إدارة مستخدمين من داخل الواجهة بعد.
- يجب اختبار الصلاحيات وإعداد أول حساب مسؤول قبل الاستخدام الفعلي.
- إعداد Supabase وسياسة حماية البيانات مسؤولية الجهة المالكة للخدمة.

خطوات الإعداد
-------------
1) أنشئ مشروعًا جديدًا في Supabase باسم Khedmet El Ameer.
2) افتح SQL Editor في المشروع، والصق محتوى supabase_schema.sql ثم نفّذه.
3) من إعدادات المشروع انسخ Project URL و anon/public key فقط.
4) انسخ config.example.js إلى ملف جديد اسمه config.js.
5) ضع Project URL و anon/public key في config.js.
6) لا تستخدم service_role key داخل التطبيق مطلقًا.
7) ارفع مجلد المشروع إلى استضافة HTTPS ثابتة (مثل استضافة مواقع تدعم الملفات الثابتة).
8) افتح رابط التطبيق على Android من Chrome، ثم اختر "إضافة إلى الشاشة الرئيسية".

إنشاء أول مسؤول
---------------
- أنشئ حسابًا عاديًا من شاشة التسجيل ببريد المسؤول.
- بعد تأكيد البريد، افتح SQL Editor ونفّذ أمر الترقية الموجود آخر ملف
  supabase_schema.sql، مع استبدال YOUR-ADMIN-EMAIL ببريد الحساب.
- لا تجعل حسابات الأمناء العامين أو أمين الخدمة متاحة بالتسجيل الذاتي؛
  يجب اعتمادها يدويًا من مسؤول موثوق.

ملاحظة تقنية
------------
ملف SQL يضع أساسًا لصلاحيات المجموعات. قبل الإنتاج، يجب مراجعة السياسات
والاختبار بحسابات منفصلة (مسؤول عام، أمين مجموعة، خادم، حساب معلق)،
واستكمال إدارة طلبات التسجيل والإشعارات والنسخ الاحتياطي.
